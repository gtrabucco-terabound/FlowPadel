# 11. Definition of Done y QA

## Funcional

Criterios cumplidos, flujos felices, errores, permisos, estados vacíos, carga, responsive y accesibilidad básica.

## Técnica

Typecheck, lint, tests, migración, rollback, logging, documentación, secrets y performance.

## Seguridad

RLS, auth, autorización, validación, idempotencia, auditoría, rate limits y datos sensibles.

## Comercial

Valor claro, onboarding, soporte, métricas, precio, demo y documentación.

## Agentes

Scope, permisos, límites, aprobación, evidencia, auditoría, fallback y pruebas.

## Gates

- Architecture Gate.
- Data Gate.
- Security Gate.
- QA Gate.
- Release Gate.
- Commercial Gate.

## Flujos críticos

Login, jugador, club, cambio de club, reserva, hold, pago, webhook, torneo, resultado, ranking, catálogo, carrito, orden, stock, importación, tarea agente y aprobación.
