# 3. Arquitectura de producto y negocio

## Dominios internos

- Flow OP: experiencia del jugador.
- Flow COS: operación del club.
- Flow MKT: marketplace común.
- Flow BOS: operación interna de Flow Padel.

## Nombres visibles

| Interno | Visible |
|---|---|
| Flow OP | Jugadores / Mi cuenta |
| Flow COS | Gestión del Club |
| Flow MKT | Marketplace |
| Flow BOS | Flow BOS |
| Agent Office | Oficina de Agentes |
| Club Agent View | Asistentes del Club |

## Modelo de negocio

### SaaS clubes
- suscripción mensual;
- canchas ilimitadas;
- planes por capacidades;
- bot comunitario o exclusivo.

### Marketplace
- ventas propias;
- ventas de terceros futuras;
- comisiones;
- promociones;
- publicidad.

### Importación
- Flow Padel compra, importa, mantiene inventario y vende.

### Automatización
- asistentes;
- marketing;
- CRM;
- reporting;
- ocupación;
- hospitality futuro.

## Responsabilidades

### Flow Padel
- proveedor principal;
- importaciones;
- stock central;
- catálogo;
- control del marketplace;
- Buyer AI.

### Club
- operación diaria;
- compra en Marketplace;
- asistentes;
- aprobación de campañas.

### Jugador
- reserva;
- compite;
- compra;
- recibe recomendaciones.

## Prioridad comercial

### Vender ahora
Reservas, torneos, ranking, pagos, agenda, turnos fijos, WhatsApp y ocupación.

### Desarrollar en paralelo
Marketplace, BOS, Import Center, Oficina de Agentes, reporting y seller foundation.

### Posterior
Hospitality, consumo en cancha, preorden, app móvil avanzada y marketplace abierto completo.
