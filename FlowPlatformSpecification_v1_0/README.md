# Flow Platform Specification v1.0

Estado: especificación consolidada para ejecución.
Fecha: 2026-07-15.
Producto: Flow Padel.

## Propósito

Este paquete define qué debe construir la flota de agentes sobre el producto real existente, en qué orden, con qué criterios de calidad y qué se puede vender desde ahora.

## Decisiones cerradas

- El MVP comercial para clubes ya existe en gran parte y debe ordenarse, estabilizarse y presentarse correctamente.
- Los nombres Flow OP, Flow COS, Flow MKT y Flow BOS son internos.
- Los clientes verán nombres simples: Jugadores, Gestión del Club, Marketplace y Empresa.
- Flow BOS es el entorno interno de Flow Padel.
- La Oficina de Agentes vive dentro de Flow BOS.
- Los clubes tendrán una vista limitada llamada Asistentes del Club.
- Buyer AI trabaja exclusivamente para Flow Padel.
- Marketplace e Import Center son prioritarios.
- Hospitality queda para una evolución posterior.
- Los agentes hacen el máximo trabajo posible y los humanos aprueban decisiones sensibles.
- El proyecto completo debe consolidarse en 6 meses.
- La salida comercial a clubes debe comenzar inmediatamente como programa fundador/beta controlada.
